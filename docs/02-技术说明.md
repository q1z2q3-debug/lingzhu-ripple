# 技术说明：为什么它不会退化成"热寂"或"过拟合"

本文只解释机制与参数，不解释哲学。给评审工程师看的部分尽量给出可复算的式子与实测值。

## 一、状态空间（L0）

9 个维度 × 3 态（阴/和/阳）= 19683，编码 `idx = Σ (trit_i + 1) · 3^i`，可逆。
卦名只做可读化（`体阴 变阴 因阴`），**不参与任何计算**。

| 维 | 全称 | 工业含义 | 典型测点 |
|---|---|---|---|
| 体 | 本体结构 | 机械/结构健康 | 振动烈度、轴承温度 |
| 用 | 功能性能 | 输出能力 | 流量比、压比 |
| 变 | 变化趋势 | 劣化速度 | 振动趋势斜率 |
| 时 | 时序节奏 | 异常持续 | 异常持续分钟数 |
| 空 | 位置布局 | 装配/空间约束 | 对中偏差 |
| 势 | 势能负载 | 负载与电流 | 负载率、电流比 |
| 因 | 工艺成因 | 工艺参数偏离 | 润滑压差、工艺偏离 |
| 果 | 结果质量 | 缺陷与一次合格率 | 缺陷数、FPY |
| 缘 | 外部关联 | 环境/上游 | 环境温度偏离、上游稳定度 |

## 二、动力学（L1）：离散格点上的漂移-扩散平衡

一步更新：

```
ψ ← (1−m)·normalize( K_λ ψ ⊙ w )  +  m·prior
w = normalize( exp( β·log prior  +  γ·coupling ) )
K_λ = exp(−λ·d_H) 的归一化卷积核（d_H 为汉明距离）
```

三个项各自解决一个具体问题，缺一个就出问题：

| 项 | 作用 | 缺失后的故障现象（本项目真实踩过） |
|---|---|---|
| `K_λ ψ` 扩散 | 让"相邻构型"共享概率，形成涟漪与邻域解释 | 无扩散 → 单点尖峰，扰动即崩 |
| `w` 势阱 | 把历史证据变成吸引子，产生非平凡稳态 | **只有扩散 → 唯一稳态是均匀分布，即"热寂"，场熵≈9.4/9.88，驻波比 0.005** |
| `m·prior` 混合 | 保证状态空间连通（不可约性），新证据一定能进入视野 | 纯乘性更新 → 概率为 0 的构型永远拿不到概率，**新故障永远进不了视野**（可达性缺失） |

### 为什么 `prior` 用"概率混合"而不是"对数平均/累加"

- **累加**：观测越多，先验越尖，置信度变成"次数的函数"→ 同一稳定工况反复巡检会无限自信，这是工业判断最危险的方向。
- **对数平均**：两条矛盾证据的"几何平均"是一条横跨两者的**山脊**，主构型会落到谁都不像的混合态，无法解读。
- **概率混合（现方案）**：矛盾证据得到**双峰先验**，场分裂到两个吸引子、中间是低谷——
  对应"两种解释并存"，主构型仍是其中一个真实构型，可读、可查。
  且锐度上限由单次观测核（`λ_p=3`）决定，与次数无关。

### 稳态性质（已数值验证，非宣称）

| 检验 | 结果 |
|---|---|
| 连续 200 步演化是否漂移 | 熵收敛至 **2.00**，主构型不变，λ 自适应至 ≈1.0–1.3 |
| 单源观测 | 熵 ≈0.8–1.1，峰值 ≈0.81（对"设备长什么样"高置信，不代表对根因高置信） |
| 四条证据（含两条冲突） | 熵 ≈1.8–2.0，峰值 ≈0.48–0.58，驻波比 ≈0.85–0.88 |
| 新证据能否夺峰 | 是（6 步整合内完成，不再滞后） |
| 场熵上界 | log 19683 ≈ 9.88，实测常态 1.7–2.0，距上界足够远 |

**未做的部分（诚实标注）**：没有给出收敛速率的解析界（如谱隙估计）。当前收敛性是经验性验证
（200 步内稳定 + 断点判据 `|ΔH| < 1e-3`），工程可用，数学上待补。

### 两个"必须分开"的算子（本项目最隐蔽的坑）

| 算子 | 性质 | 用途 | 混用后果 |
|---|---|---|---|
| `_blur` | 一步转移核：只能走一格，行随机、反射边界、严格守恒 | 动力学演化 | 用它生成先验 → 先验支撑只有半径 1，条件化时"阴→阳"跨两格没有概率，场退化为均匀（熵冲到 8.7） |
| `_kernel_for` | 静态核 `exp(−λ·d_H)`：沿每轴 3×3 矩阵精确可分离，覆盖全部 9 跳 | 立先验 | 用它做动力学 → 一步跨 9 格，不是扩散过程，无时间尺度可言 |

### 边界反射为什么是硬要求

阴/和/阳 是一条 **3 格点路径**，端点只有 1 个邻居。普通卷积把越界当 0，端点行和 < 1，
转移核就不是行随机的：每步丢质量，**全阴/全阳这类角落构型被系统性削弱**，场朝中间偏，
表现为"熵读数莫名偏高、条件化后接近均匀"。修复方式是把缺失邻居的质量还给自身（反射），
使每轴行和恒为 1 且矩阵对称——这是"场可计算、概率可解释"的最底层前提。
实测修复前后同一组参数熵差 3~4，说明这不是细节，而是建模错误。

## 三、计算复杂度

朴素做法要算任意两构型的汉明距离核 → O(N²)=3.9 亿次，不可用。
因 `exp(−λ·d_H)` 在 9 个维度上**可分离**，等价于沿每条轴做一次三邻域卷积：

```
O(9 × 3 × N) = 9×3×19683 ≈ 5.3 万次浮点，实测单步 1.26 ms
```

这是它能进生产节拍（而不是只能做离线演示）的根本原因。

## 四、因果免疫（L4）

三层查询，顺序固定，**不允许越层编造**：

1. **免疫层**（已核验或同根因 ≥3 次）：毫秒级返回 `root_cause / fix_action / verified / hit_count`
2. **相似层**：文本 0.55 + 拓扑 0.45 的复合分 ≥0.52
3. **待推理**：`root_cause = null`，明确交上层 Agent，并强制进入中和路径

匹配分数：

```
score = 0.55 · Jaccard(字二元组) + 0.45 · (1 − d_H/9)
```

为什么拓扑权重接近一半：同一故障在不同工单里措辞千差万别（"轴承响""振动大""温度高"），
但测点构型高度一致。纯文本检索在工业场景召回很低；纯拓扑又会把"看起来像但不是"的案例混淆。**两者互补。**

复合故障：返回前 3 候选，若 top1 与 top2 分差 <0.25 → 判 `composite_ambiguity`，降级为**待复核 + 并联处置**，
不允许单根因派单。这是"不许编造"在工程上的具体落法。

## 五、幻觉中和（L7）：区分"证据不足"与"认知弥散"

早期版本把场熵当唯一闸门，结果**已知故障也被拦**（实测：免疫匹配 0.95 却因熵高被判"被中和"），
这是过度保守导致的另一种失效。现版本按来源分流：

| 结论来源 | 判定 | 理由 |
|---|---|---|
| 命中免疫/相似层 | 只看匹配度、置信、是否核验、候选分歧 | 证据是硬的，场熵高只说明"见过的不多"，不代表结论错 |
| 推理型（无落地根因） | 无根因即中和；熵 >2.6 亦中和 | 推测必须有地基，否则不许出门 |
| 高层级记忆（信念/身份/使命） | 阈值收紧 0.2 | 越抽象的结论，越要证据 |

状态机：`通过`（可派单）/ `待复核`（给候选 + 人工确认）/ `被中和`（不出结论，转人工）。

## 六、反事实：条件化，不是"再喂一条证据"

两种做法都试过，第一种是错的：

| 做法 | 问题 |
|---|---|
| 影子场 = 复制主场 + 再注入一条"干预构型"证据 | 旧构型仍占峰，干预被稀释，"改了也没变化"；且熵跨场比较是伪比较（源数不同） |
| **条件化** ψ(x \| x_i = v_i)（现方案） | 直接问"若该维确定为阳，最可能的整体构型是什么"，答案就是预案要的结论 |

判读指标不是熵（条件化必然压缩支撑集，熵单向下降没有信息量），而是：

```
干预可行度 compat = 修复后状态在当前先验里占的质量
```

- `compat < 0.05`：该维现在明显偏离 → **主要抓手**，先修它，修完复测；
- `0.05–0.30`：有偏离但不主导 → 次要抓手；
- `> 0.30`：已接近目标状态 → 干预无收益，优先级下调。

可逆性由结构保证（条件化场是独立对象），不依赖"推完再写回"；自检项会核对主场构型与熵完全不变。

## 八、七层记忆（L6）

环境 → 行为 → 能力 → 信念 → 身份 → 使命 → 灵性。晋级条件：该层 ≥5 条且末条置信 ≥0.8。
工程作用：让"点检记录"逐级沉淀成"可复用能力"和"经核验的信念"，而不是每次从零算。
对外表述建议只说"经验分层沉淀与晋级"，不用"灵性"这类词进汇报材料。
